## 二、Docker / OrbStack 管理（阶段 11）

`Sources/Core/DockerProbe.swift`：
- `cli()` 候选顺序：`/usr/local/bin/docker`（本机指向 OrbStack xbin）→ `~/.orbstack/bin` → homebrew → Docker.app → `/usr/bin` → `which`
- `scan()`：`orb status` → `docker version --format {{.Server.Version}}`（**超时 12s**，daemon 没起会卡）→ 引擎识别（`docker info --format {{.Name}}|{{.OperatingSystem}}` 匹配 orbstack/docker desktop/colima/rancher）→ 容器 / 镜像 / `system df`
- 容器解析 `docker ps -a --no-trunc --format '{{json .}}'`；`shortPorts` 把 `0.0.0.0:6379->6379/tcp, [::]:6379->6379/tcp` 归一成 `6379→6379` 并去重；`shortStatus` 把 `Exited (0) 2 min ago` 截成 `Exited (0)`
- 动作：start/stop/restart/rm、`orb start|stop`、logs（tail）
- `ContainerVerb` 枚举给整句中英文案（不用模板拼动词，中英句式差异大）

`Sources/Views/DockerView.swift`：引擎状态卡（4 tile + 可回收空间）、**引擎未起时的引导卡**（OrbStack 在就 `orb start` 按钮，否则提示 Docker Desktop/colima，并折叠展示 docker 原始报错 3 行）、容器/镜像 tab、容器表（5 列 + 起点停/重启/日志/删）、镜像表、日志 sheet。侧栏「系统」组新增「容器」，⌘8。

实测：本机 OrbStack 当时是 Stopped，拉 alpine 造了 3 个容器（2 running / 1 exited）验证表格，验完 `docker rm -f` + `docker rmi` 清干净并 `orb stop` 恢复原状。

## 三、AI 友好的 CLI（阶段 12）

`Sources/Core/CLIRunner.swift`，入口判定：`args[1]` 不以 `--` 开头即走子命令（旧的 `--probe/--action/--snapshot/--bench` 全部保留）。

**四条硬约定**：
1. 全部查询支持 `--json`，信封 `{ok, schema:1, tool, version, command, data}`；失败 `{ok:false, error:{code,message}}`
2. 字段名小写下划线、状态用枚举字面量（started/stopped/running/exited），不放中文
3. 退出码 0/1/2（成功/失败/用法错误）
4. `help --json` 输出 16 条命令清单 + 信封 schema + exit_codes，供 AI 自发现

命令：version / list / status / start|stop|restart|run / logs / containers / container / images / docker-status / timers / timer / runtime / doctor / help。

**动作类命令执行完必回读真实状态**（不只报「已发送」）：服务动作输出 `previous_status` + `elapsed_ms`；容器动作输出 `previous_state` + 回读的 `state`。

错误码：`bad_usage` / `not_found` / `not_installed` / `action_failed` / `engine_down` / `cli_missing` / `no_log`。
